# I-CARE-AI

### AI-Powered Parenting Education Web Application
Developed an interactive AI web application designed to enhance parent-child communication and bonding through **natural language processing** and **computer vision**.

Implemented a custom chatbot trained to mimic a child’s speaking style using OpenAI's API, enabling realistic conversation simulations between parents and child personas.

Built a two-player motion-based game to promote physical interaction and emotional bonding, using MediaPipe and YOLO for real-time multi-person pose tracking.

Combined natural language understanding and vision-based interaction to provide a holistic, AI-assisted parenting education experience.
